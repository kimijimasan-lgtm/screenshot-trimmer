Anthropic APIキー

要約機能に必須・有料
字幕要約機能では、Anthropic社のAI「Claude（クロード）」が字幕テキストを読み取り、要点をまとめます。いわばClaudeはこのアプリの要約係です。

Claudeに作業をお願いするには「APIキー」が必要です。APIキーとは、Claudeを使うための会員証のようなもので、あなた専用の長い文字列です。以下の手順で取得して、下の入力欄に貼り付けてください。
💰 料金の目安（字幕要約1回ごと。日本語を安全側（1文字＝1.5トークン）で見積もり、1ドル＝150円として計算した概算です。実際のレートや文章量により変わります）
・短い範囲（5〜10分程度の字幕）を要約：1回あたり1〜2円程度
・一度に要約できる最大の長さ（50,000文字）を要約：1回あたり最大でも13円程度
・「項目別（解説）」は出力が長いため、1回あたりの料金が要点まとめより少し高くなります（短い範囲で3〜5円程度、最大の長さ（15,000文字）で最大でも13円程度）
料金はこのアプリの開発者にではなく、Anthropic社に直接支払う形になります。
① 事前準備：利用残高（クレジット）の購入
・Anthropicの支払いは「前払い」です。APIキーを作る前後どちらでもよいので、利用のための残高（クレジット）を購入しておく必要があります
・コンソール画面の「Billing（請求）」ページで「クレジットを購入」を押し、購入する金額（米ドル）を入力します。初回は5ドル程度から購入できます（金額の目安は変更されることがあります）
・支払いにはクレジットカードまたはデビットカードが必要です（PayPalや電子マネーは使えません）
・（任意）使いすぎが心配な場合は、「Organization settings」→「Billing」→「Spend limits」で、1か月に使える上限金額を自分で設定できます
② APIキーの取得手順
1.下のアドレスをブラウザで開きます（APIキーの一覧ページに直接移動します）：
https://platform.claude.com/settings/keys
2.アカウントを作ってログインします（Googleアカウントでもログインできます）
3.画面に表示される「Create key」ボタンを押します
4.名前を入力します（あとで自分が分かればどんな名前でもOK）。有効期限（Expiration）や利用者（Linked account）の欄は、そのままで大丈夫です。入力できたら、もう一度「Create Key」を押します
5.表示された文字列（sk-ant-... で始まる長い文字列）をコピーします
6.コピーした文字列を下の入力欄に貼り付けて「保存」を押します。貼り付けたら、1で開いたページは閉じてOKです
⚠ 鍵の文字列は作成した直後の1回しか表示されません。表示されたら、すぐにコピーしてください。画面を閉じると二度と見られないのでご注意ください。また、この鍵は他人に教えないでください（他人があなたの利用残高を使えてしまいます）。
APIキー：
🔒 入力したAPIキーは、このブラウザの中だけに保存されます。外部に送信されることはありません（要約を生成するときだけ、Anthropic社のサーバーに安全に送信されます）。

YouTube Data API v3 キー

任意・無料
動画一覧に表示する、チャンネルの丸いアイコン画像を取得するために使います。このアプリ自体の動作には必要ありません。入力しなくても、動画の読み込みやキャプチャ、字幕要約はすべて問題なく使えます。

こちらも「APIキー」という、あなた専用の文字列を使います。キーの取得も利用も無料です（Googleの仕様で、プロジェクト作成時にカード登録を求められることがありますが、料金は発生しません）。

チャンネルアイコンが表示されないときは、ここでキーを確認してください。
💰 料金について
完全に無料です。1日に10,000回分の「無料のひきかえ券（割り当て）」が用意されており、チャンネルアイコンの取得は1回につき券1枚しか使いません。使い切ることはまずありませんが、万一使い切った場合も自動で課金されることはなく、その日は取得が一時的に止まるだけです（翌日またアメリカ時間の深夜に回復します）。
※ 無料枠の範囲内であれば、カードを登録しても課金されません。
取得手順（全部で7ステップ。いちばん大事なのは手順4の「有効にする」です）
1.下のアドレスをブラウザで開きます：
https://console.cloud.google.com/
2.Googleアカウントでログインします（普段お使いのGoogleアカウントでかまいません）
3.画面左上、「Google Cloud」のロゴの右にある丸いボタンを押します（すでにプロジェクトがある場合はそのプロジェクト名、ない場合は「プロジェクトを選択」と表示されています）
　開いた小さなウィンドウの右上にある「新しいプロジェクト」を押します
　プロジェクト名は何でもかまいません。
「請求先アカウント」の欄が赤くなっている場合は、
▼を押して一覧から選びます
　「作成」を押します。
作成には数十秒かかることがあります。
完了したら、同じボタンをもう一度押して、
作ったプロジェクトが選ばれていることを確認します
　※ すでにGoogle Cloudのプロジェクトをお持ちの場合は、新しく作らず、そのプロジェクトを使っても大丈夫です
⚠ 「請求先アカウントは必須です」と赤く表示されたとき
・一覧に請求先アカウントが出ている場合は、
それを選んで「作成」を押してください
・一覧が空の場合は、Googleが本人確認のために、
支払い方法（クレジットカードなど）の登録を求めています。
YouTube Data APIの利用自体は無料枠の範囲で課金されません。
登録だけで料金が発生することもありません。
・カードの登録に抵抗がある場合は、このキーは任意なので、
入力せずに進めても、動画の読み込みやキャプチャ、
字幕要約は問題なく使えます
（チャンネルのアイコンだけ表示されません）
・「組織なし」「親リソース 組織なし」のままで大丈夫です。
変更しないでください
④ 「YouTube Data API v3」を有効にします（ここが一番大事です）
・左上のメニュー（≡）から「APIとサービス」→「ライブラリ」を開きます
・検索欄に「YouTube Data API v3」と入力し、表示された項目を選びます
・青い「有効にする」ボタンを押します
・少し待つと、ボタンが「管理」に変わります。これが「APIが有効になった」というしるしです。この表示に変わったことを確かめてから、次の手順に進んでください
⚠ここを飛ばすと、次のキー作成の手順で「APIの制限の選択」のプルダウンが空のままになり、先に進めなくなります
5.左のメニューから「APIとサービス」→「認証情報」を開き、上部の「認証情報を作成」ボタンを押して「API キー」を選びます
　※ 入力の途中で画面が消えてしまっても、やり直しは問題ありません。もう一度同じ手順をたどればOKです
6.表示された文字列（AIzaで始まる文字列）をコピーして、下の入力欄に貼り付けます
7.（推奨・安全のため）作成したキーの「キーを制限」を押します。「APIの制限」は必須の項目（*印が付いています）なので、「キーを制限」を選び、プルダウンを押して「YouTube Data API v3」にチェックを入れ、「OK」を押してから保存します。これで、万一この鍵が漏れても他のサービスには使われません
　※ プルダウンの一覧に「YouTube Data API v3」が出てこないときは、手順4がまだ済んでいません。画面に出ている「APIライブラリ」のリンクから手順4に戻ってください
⚠ このキーは無料枠のみなので高額請求の心配はありませんが、念のため他人には教えないでください。手順7の制限をかけておくと、より安全です。
APIキー：
🔒 入力したAPIキーは、このブラウザの中だけに保存されます。外部に送信されることはありません（チャンネルアイコンを取得するときだけ、Google社のサーバーに安全に送信されます）。
